# Покадровая разница видео

Скрипт `src/video_diff.py`. В начале можно изменить `FILE_1` и `FILE_2` и запустить
без аргументов, как `src/trim_video.py`. Либо передать два файла:

```powershell
python src/video_diff.py "before.mp4" "after.mp4" -o "diff.mp4"
```

Усиленная разница с отсечением слабого шума:

```powershell
python src/video_diff.py "before.mp4" "after.mp4" -o "diff_x4.mp4" --gain 4 --threshold 3
```

Кадр 0 сравнивается с кадром 0, кадр 1 с кадром 1 и так далее. Выходной цвет —
абсолютная разница каналов: `abs(A - B)`. Одинаковые пиксели чёрные, различия
сохраняются. `--threshold` обнуляет разницу канала не больше заданного значения
до усиления, `--gain` умножает остальные значения с ограничением до 255.
По умолчанию усиление 1, порог 0. Перемещения и масштаб автоматически не
выравниваются: они тоже должны быть видны как разница.

Нужны одинаковый размер, FPS и число кадров. Скрипт проверяет эти условия;
совпадение начала по содержимому предполагается, а не определяется автоматически.
Различия от кодирования тоже попадут в результат. Выход — MP4 (H.264, CRF 30),
без звука, с исходным FPS. Ширина и высота по умолчанию уменьшены в 4 раза:
3840×2880 → 960×720. Сначала вычисляется разница, затем уменьшается через INTER_AREA.
`--downscale 1` сохраняет размер; `--crf 34` усиливает сжатие, `--crf 23` повышает качество.
Размеры округляются вниз до чётных для H.264. Это визуальная разница: выходное
видео само кодируется с потерями, не является точной матрицей чисел.

Без `-o` результат сохраняется в `artifacts/diff/<имя первого видео>_diff_small4.mp4`
(число соответствует `--downscale`)
рядом со скриптом. Существующий результат не перезаписывается: выберите другое
имя через `-o`. Исходники не изменяются.

Зависимости: OpenCV и FFmpeg (`pip install opencv-python imageio-ffmpeg`).
Поддерживается FFmpeg из PATH, пакет imageio-ffmpeg и его локальная установка в `.cache/video_diff`.
