# Пример 1: DJI O4 Pro, штатная линза, спокойный полёт

`o4pro_13-17s.MP4` — 4.8 с (12.6–17.4 с) из `DJI_20260905181949_0005_D.MP4`,
3840×2880, 50 fps, HEVC 10‑bit, вырезано без перекодирования вместе с
телеметрией (`src/trim_video.py`). Это участок, на котором в стабилизированном
Gyroflow видео кадр мелко дрожит по крену, хотя дрон летит ровно.

## Запуск

Клип `o4pro_13-17s.MP4` (73 МБ) лежит не в репозитории, а на странице Releases;
скачайте его в эту папку, затем

```bat
run.bat
```

то есть `fix_telemetry.bat o4pro_13-17s.MP4 --plots`. Первый прогон измеряет
картинку (~1.5 мин для этого куска), потом собирает `o4pro_13-17s_telemetry_fixed.mp4`.
Его загрузить в Gyroflow как данные движения (Motion data) к исходному клипу.

## Что было не так и что сделано

**Крен.** Слитая ориентация DJI дрожит по крену от кадра к кадру, картинка при
этом гладкая. Измерено на этом куске (спокойные кадры, <20 °/с, 157 кадров):

| | дрожание крена, °/кадр | то же в px у края кадра |
|---|---|---|
| телеметрия DJI | 0.1105 | 4.6 |
| исправленная телеметрия | 0.0187 | 0.8 |
| реальное движение (по картинке) | 0.0075 | 0.3 |

Правка крена: rms 0.045°, пик 0.20°. Тангаж и рыскание: выбросов телеметрии
нет, событий нет, винеровское шумоподавление выше 4 Гц дало 0.023° rms.
Тайминг: постоянный сдвиг 0 (на 4.8 с мало быстрых кадров, чтобы его измерить;
на полном клипе он измерен и тоже 0), покадровая поправка на экспозицию до +1 мс.

Проверка: Gyroflow CLI читает файл ровно так, как записан (расхождение 0.003°).

## Что не идеально

- Остаток дрожания 0.0187 против порога картинки 0.0075: крен правится только
  выше 4 Гц и с весом по скорости, ниже 4 Гц телеметрия оставлена как есть,
  потому что интеграл измерения по картинке дрейфует. Остаток 0.8 px у края
  кадра на глаз не виден.
- На таком коротком куске калибровки конвейера (константа тайминга, винеровские
  кривые, ось крена, канал‑свидетель) не набирают статистики и берут значения
  по умолчанию; отчёт `o4pro_13-17s_fix_report.json` это показывает
  (`corr nan`, `default curve`). На полном клипе они измеряются.
